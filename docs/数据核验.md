# 地理数据核验记录

日期：2026-10-25。范围：供 V0.1 本地演示使用，未作全量权威审图与逐项事实审定。

## 已完成的结构检查

- `public/data/china.json` 有 35 个 feature：34 个行政区，以及 `100000_JD` 空名称边界辅助 feature。辅助 feature 不得计入行政区数量。
- `src/regionCatalog.ts` 的中国目录按实际数据顺序匹配并检查了 34 个行政代码、名称、行政中心，包含 23 省、5 自治区、4 直辖市、2 特别行政区。
- 普通省使用“省会”，自治区使用“首府”；直辖市及特别行政区不使用省会表述。台湾使用台北作为教学行政中心标注，不表达实际管辖情况。
- 香港、澳门的坐标是城市定位点，不是其政府总部精确坐标。
- 亚洲国家目录为 49 个课堂条目，包含俄罗斯作为跨洲教学补充。另有台湾、香港、澳门 3 个中国地区条目，不归为独立国家。
- 目录不是国家承认清单，也不是联合国 M49 亚洲条目的逐字复制。俄罗斯在 M49 归欧洲，本工具为地理跨洲展示补充纳入。
- 增补了低分辨率世界边界缺失的小国新加坡、马尔代夫、巴林；它们通过目录/标注定位，不虚构边界。
- 世界数据 177 个 feature，并不完整覆盖所有小国家；`Palestine` 的 ADM0_A3 实际为 `PSX`，目录使用 PSX 并支持 PSE 别名。`N. Cyprus` 不独立计入国家目录。

## 教学精选要素

当前源码覆盖：9 项山脉/高原/平原（青藏高原、喜马拉雅、天山、阿尔泰、昆仑、德干、伊朗、蒙古高原、西西伯利亚平原），6 条河流（长江、黄河、湄公河、恒河、印度河、叶尼塞河），以及经纬网和5条特殊纬线。

- 河流折线是手工概化的方向示意，不能用于沿河城市定位、流域判断、国界判断或距离测量。河道精准程度未核验。
- 山脉和高原用单个标签点表达大范围地形，不是地形范围边界。
- 喜马拉雅与青藏高原南缘的位置关系可参照[印度空间研究机构 IIRS GeoHimalaya](https://geohim.iirs.gov.in/)。
- 当前天山描述“位于塔里木与准噶尔盆地之间”仅适用于中国境内主要段落，建议主应用改为“横贯亚洲中部；中国境内主要段落位于塔里木与准噶尔盆地之间”，避免把整条山系缩成境内段落。
- 回归线23.44°、极圈66.56°为近似值；黄赤交角缓慢变化，不宣称精确到实时天文历元。
- 原 geography.ts 特殊纬线赤道详情会显示“0°。”，建议改成“纬度0°，划分南北半球”。

## 地图上线前仍需处理

Natural Earth 世界底图和中国边界数据本次没有经过中国地图审查合规核验；包括南海诸岛、争议边界、世界底图台湾独立 feature 的绘制合并等。GeoJSON 的来源与可取得性不等于具有审图号。课堂正式使用和公开上线前，应核实数据授权、边界表达及适用的地图审核要求。演示界面应明确显示“教学示意，非审定地图”，不能声称已完成审图。

## 应用接口

- `countryCatalog`：49 条；id 为三字代码（巴勒斯坦用 Natural Earth 的 PSX），kind 为 country。
- `provinceCatalog`：34 条；id 为行政代码字符串，kind 为 province，administrativeKind 保留具体类型。
- `provinceDetails`：行政代码 → capital / description / administrativeKind。
- `asiaCatalog`：包含上述49国家及3中国地区条目；`findAsiaRegion` 支持英文名称及代码别名。
- lat/lng 是大致城市标注坐标，适合镜头定位，不是测绘级数据。

## 显示坐标约定（本轮修复）

国家条目的 lat/lng 保留目录中的首都或政府驻地城市示意坐标；Natural Earth 的 LABEL_X/Y 单独作为 labelLng/labelLat，只有区域名称摆放和区域镜头使用。详情不再将底图标签位置描述为首都位置。巴勒斯坦首都图层在拉马拉处显示“拉马拉（政府驻地）”，完整首都说明保留在详情中。
